# 🎬 AI Viral Kids Studio

**Aplikasi Pembuatan Konten Video Animasi Anak dengan AI**

---

## 📋 Tentang Aplikasi

AI Viral Kids Studio adalah aplikasi canggih untuk membuat konten video animasi untuk anak-anak. Dengan menggunakan teknologi AI, aplikasi ini dapat:

- ✅ Menghasilkan judul viral (10 judul sekaligus)
- ✅ Membuat karakter utama dengan konsistensi visual
- ✅ Menulis skrip cerita animasi yang menarik
- ✅ Membuat storyboard 6-panel per scene
- ✅ Menghasilkan prompt untuk AI Image Generator
- ✅ Menghasilkan prompt untuk AI Video Generator
- ✅ Membuat thumbnail High-CTR
- ✅ Menghasilkan SEO metadata untuk YouTube
